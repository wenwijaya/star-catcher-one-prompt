Star Catcher — a tiny browser game built by an AI agent from ONE prompt: a basket catches falling stars for 60 seconds while the speed climbs, golden stars are worth more, and bombs cost a life. Made for make.fun's "The agent builds a game from one prompt" bounty; the entry video shows the prompt, the agent working, and the finished game running.

## Run it

```sh
open index.html
```

No build step, no libraries — just open `index.html` in any browser. Move with the mouse, touch, or arrow keys. `main.ts` copies `POST.json` to `/output` for the make.fun grader.
